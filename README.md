# Inversiones

Los instrumentos financieros uno por uno: renta fija con su precio, duración e inmunización, acciones e índices, futuros, forwards, swaps, opciones con el árbol binomial, divisas y productos estructurados, con una calculadora para cada uno.

**Ver en línea:** https://aaramirez.github.io/inversiones/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
